# Security Policy

## Supported versions

Security fixes are prioritized for the latest release and the current development branch.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's repository security reporting feature (Security Advisories) when available. If private reporting is unavailable, contact the maintainer directly through a private channel before publishing details.

Please include:
- A concise description of the issue and its potential impact.
- Steps to reproduce, a minimal proof of concept, or relevant logs (with personal data removed).
- The affected version, platform, and device details.

Please do not publicly disclose exploit details before a fix or mitigation is available. Avoid attaching personal reading history, session data, database exports, or other sensitive information.

## Privacy and security notes

PageClock is designed to store focus and reading data locally. Do not include real user data, credentials, signing keys, keystore files, tokens, or private database exports in bug reports, commits, or pull requests. Review dependencies and changes that affect storage, imports/exports, permissions, notifications, or synchronization with particular care.

Security reports are acknowledged and assessed as time and resources permit; no response or remediation timeline is guaranteed.
